# EveryMacTool 1.0.5

- Fix delayed-looking power values by reading the live AppleSMC battery rail (`PPBR`) while on battery and live DC-in power (`PDTR`, with voltage/current fallback) while on adapter power.
- Fall back to AppleSmartBattery readings when the SMC or expected keys are not available.
- Show which telemetry source is feeding the current power readings.
- Include the required MIT attribution for the adapted read-only SMC reader in `THIRD_PARTY_NOTICES.md`.

The hardware publishes these SMC readings at about 1 Hz on supported Apple silicon; the application polls every 250 ms so each new hardware reading appears promptly when macOS exposes it. A 10 ms sensor update is not claimed.
